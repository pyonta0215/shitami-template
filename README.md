# shitami（需要の下見）・ 調べ切り

YouTube で始めたいテーマを1つ入れると、1日かけて次の2つを探す道具です。

- **① 穴場**：投稿している人は少ないのに、見られている小さなテーマ
- **② 真似先**：後から入って伸びた、大手ではないチャンネル。最初の当たりまでに何本・何日かかったか

結果のページには、まず「穴場の上位3つ・真似先の上位3つ・次にやること1つ」を出し、伸びている動画のサムネ一覧、「このテーマはやめておく」目安、自分で確かめることのリストを続けます。
「やるべき／やめるべき」は書きません。判断の材料です。

> この道具は、作者がノウハウ図書館の記事やオフ会などで見聞きした内容を、自分なりに噛み砕いて形にしたものです。作者は YouTube での収益化には至っていません。結果は収益や成果を約束するものではありません。非公式の道具であり、YouTube・Google・Cloudflare とは関係ありません。

## 使い方は2通り

| | スプレッドシート版（おすすめ） | Cloudflare 版（エンジニア向け） |
|---|---|---|
| 準備 | シートをコピーして、承認を押すだけ | Cloudflare に公開し、YouTube の APIキーを作って入れ、Access で鍵をかける |
| APIキー | 要らない | 要る |
| 費用 | 0円 | 0円 |
| 使う場所 | パソコン（結果の一覧はスマホのシートアプリでも見られる） | パソコン・スマホ |

どちらも YouTube Data API の無料枠を使います。検索は1日100回までで、調べ切り1回で最大85回使うので、**1日に調べられるテーマは1つ**です。枠は太平洋時間の0時（日本時間の16時。11月〜3月は17時）に戻ります。

## スプレッドシート版

### 始め方

1. 配布しているスプレッドシートを開き、「ファイル」→「コピーを作成」（**リンクは公開後に差し替え**）
2. コピーしたシートを開くと、メニューに「shitami」が出ます（出ないときは再読み込み）
3. 「shitami」→「調べ切る」を押すと、初回だけ Google の承認画面が出ます
   - 「このアプリは Google で確認されていません」と出たら、「詳細」→「（安全ではないページ）に移動」→「許可」
   - 自作の Apps Script では必ず出る表示です。コピーした時点で、プログラムの持ち主はあなた自身になります。作者に情報が送られることはありません
   - 求める権限は「YouTube アカウントの表示」「このスプレッドシートの編集」「外部への接続（検索候補を取るため）」「時間で動く処理（続きを自動で動かすため）」「サイドバーの表示」の5つです
4. 右に出るサイドバーでテーマを入れ、「誰に見てもらう動画？」を選んで「調べ切る」

調べ切りは裏で進みます（1回6分までの制限があるので、区切りながら自動で続けます）。サイドバーやシートを閉じても止まりません。
終わったら「結果を開く」で、結果のページが開きます。過去の結果は「shitami」→「結果を開く」と、「結果」シートから見られます。結果は30日で自動的に消えます（YouTube API の規約に合わせています）。

### （任意）お金の根拠を Web で調べる

「shitami」→「OpenAI のキーを設定」でキーを入れると、「お金が動いている根拠」と「成り立たない根拠（反証）」を Web 検索で調べる欄が埋まります（1回 約7円）。キーはあなたの Google アカウントの中にだけ保存され、シートを共有しても他の人には見えません。OpenAI 側で月の利用上限を必ず設定してください。

### 止め方・消し方

- コピーしたスプレッドシートを削除すれば、すべて消えます
- 承認を取り消すには、Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」から外します

### 自分でシートを作る場合

配布のシートを使わずに作ることもできます。

1. 新しいスプレッドシートを作り、「拡張機能」→「Apps Script」
2. `gas/dist/` の3つのファイル（`Code.js`・`Sidebar.html`・`appsscript.json`）の中身を、同じ名前のファイルとして貼る（`appsscript.json` は「プロジェクトの設定」で「appsscript.json をエディタで表示」をオンにすると出ます）
3. 保存してシートを再読み込みすると、メニューに「shitami」が出ます

## Cloudflare 版（エンジニア向け）

スマホからも使いたい人、自分の環境に立てたい人向けです。AI エージェント（Claude Code、Codex など）でこのフォルダを開いて **「AGENTS.md に沿ってセットアップして」** と頼めば、手順1〜5を案内しながら進めてくれます。

### 1. このテンプレートを手元に置く

GitHub の「Use this template」で自分のリポジトリを作るか、そのままダウンロードします。

### 2. Cloudflare にログインする

```bash
npm install
npx wrangler login
```

### 3. YouTube の APIキーを作って入れる

1. [Google Cloud コンソール](https://console.cloud.google.com/) で**この道具専用の新しいプロジェクト**を作る（YouTube API の規約で、1つのプロジェクトを複数のアプリで使い回せないため）
2. 「API とサービス」→「ライブラリ」で **YouTube Data API v3** を有効にする
3. 「認証情報」→「認証情報を作成」→「API キー」。「API の制限」で **YouTube Data API v3 だけ**を選んで保存する
4. キーを Cloudflare に入れる（画面に貼り付けを求められます。キーはファイルにもチャットにも書かないでください）

```bash
npx wrangler secret put YOUTUBE_API_KEY
```

### 4. 公開する

```bash
npx wrangler deploy
```

`https://shitami.<あなたのサブドメイン>.workers.dev` のような URL が出ます。

### 5. 鍵をかける（Cloudflare Access）

1. Cloudflare のダッシュボード →「Workers & Pages」→ `shitami` を開く
2. 「Access」タブ →「Protect this Worker behind Access」
3. 「すべてのトラフィック」を保護する設定にし、ポリシーで自分のメールアドレスだけを許可する →「Apply Access」

初めて Access（Zero Trust）を使うときは、無料プランの登録でクレジットカードの入力を求められます（無料プランでは課金されません）。設定できると、画面上部の「鍵がかかっていません」の表示が消えます。

### 6.（任意）お金の根拠を Web で調べる

```bash
npx wrangler secret put OPENAI_API_KEY
```

### 費用

| 項目 | 無料枠 | 月額 |
|---|---|---|
| Cloudflare Workers | 1日10万リクエスト（調べ切り1回で数千回） | 0円 |
| Cloudflare KV（台帳と結果） | 1日1,000回の書き込み、1GBまで | 0円 |
| Cloudflare Access | 50人まで | 0円 |
| YouTube Data API | 1日10,000 units（検索は100回）。超えると止まるだけで課金はない | 0円 |
| OpenAI（任意） | — | 1回 約7円 |

### 止め方・消し方

- 使うのをやめる：`npx wrangler delete`
- キーを無効にする：Google Cloud コンソールの「認証情報」でキーを削除する
- 保存した結果を消す：Cloudflare のダッシュボード →「Storage & Databases」→「KV」で `shitami` の名前空間を削除する

### 仕組み

```
あなたのブラウザ（計算する）
   │  /api/*
   ▼
Cloudflare Access（あなただけ通す）
   ▼
Worker（キーを付けて中継するだけ。1日1回の台帳、結果の保存）── KV（30日で消える）
   ├─▶ YouTube Data API
   ├─▶ YouTube の検索候補
   └─▶ OpenAI（任意）
```

- 調べ切りの計算はブラウザの中で回します。Cloudflare の無料プランでは1回の処理に使える時間が短く、数千回の呼び出しを Worker の中で回せないためです
- 始める前に1 unit だけ使ってキーを確かめます。キーが間違ったまま1日分を使い切ることはありません

### もう一段かたくする（任意）

Access の後ろにあることを Worker 側でも確かめたい場合は、`wrangler.jsonc` の `ACCESS_TEAM`（Zero Trust のチーム名）と `ACCESS_AUD`（Access アプリケーションの AUD タグ）を入れて、もう一度 `npx wrangler deploy` してください。

## 結果の見方

- **サムネ**は並べて眺める材料です。伸びた理由をサムネだけのせいにしないでください
- **真似**は題名の型までにして、中身で1つ足すものを決めてください。テンプレートどおりの量産は、YouTube の収益化の対象外になることがあります
- **撤退の目安**に当たったら、近い語の穴場を見てみてください
- **自分で確かめること**には、所要時間の目安が付いています。上から順に

## 分かっている制約

- YouTube の検索候補は公式に公開されていない仕組みを使っています。使えなくなったら、テーマの語だけで探します
- サムネのクリック率は、チャンネルの持ち主しか見られません
- ライブ配信は再生時間が0秒で返るので、形式は「不明」として分けています

## 開発

```bash
npm test             # テスト（スプレッドシート版は偽の Apps Script 環境で最後まで通す）
npm run build:gas    # スプレッドシート版を gas/dist/ に作る
npm run dev          # Cloudflare 版を手元で動かす（.dev.vars に YOUTUBE_API_KEY=... を書く。git には入りません）
```

計算の中身は `src/deep/`（段の配分は `src/deep/plan.js`）です。スプレッドシート版は `gas/`、Cloudflare 版は `worker/`・`web/`・`public/` です。
