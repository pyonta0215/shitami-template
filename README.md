# shitami（需要の下見）・ 調べ切り

YouTube で始めたいテーマを1つ入れると、1日かけて次の2つを探す道具です。

- **① 穴場**：投稿している人は少ないのに、見られている小さなテーマ
- **② 真似先**：後から入って伸びた、大手ではないチャンネル。最初の当たりまでに何本・何日かかったか

あわせて、伸びている動画のサムネ一覧、「このテーマはやめておく」目安（撤退条件）、機械では分からないので自分で確かめることのリストを1枚のページにまとめます。
「やるべき／やめるべき」は書きません。判断の材料です。

自分の Cloudflare アカウントに立てて、自分だけで使います。**費用は0円**で動きます（Web 調査を足す場合のみ OpenAI の利用料が1回 約7円）。

> この道具は、作者がノウハウ図書館の記事やオフ会などで見聞きした内容を、自分なりに噛み砕いて形にしたものです。作者は YouTube での収益化には至っていません。結果は収益や成果を約束するものではありません。非公式の道具であり、YouTube・Google・Cloudflare とは関係ありません。

## 1日1回の理由

YouTube Data API の無料枠では、検索が1日100回までです。調べ切り1回で最大85回使うので、1日1テーマにしています。
枠は太平洋時間の0時（日本時間の16時。11月〜3月は17時）に戻ります。

## 用意するもの

- Google アカウント（YouTube の APIキーを作る）
- Cloudflare アカウント（無料。2段階認証を設定しておく）
- Claude Code（作業の大半を任せます）

## 立て方

Claude Code にこのフォルダを開いて **「CLAUDE.md に沿ってセットアップして」** と頼めば、手順1〜4を案内しながら進めてくれます。あなたが手を動かすのは、ログインの許可、APIキーの発行と貼り付け、Access の設定です。

### 1. このテンプレートを手元に置く

GitHub の「Use this template」で自分のリポジトリを作るか、そのままダウンロードします。

### 2. Cloudflare にログインする

```bash
npm install
npx wrangler login
```

ブラウザが開くので「Allow」を押します。

### 3. YouTube の APIキーを作って入れる

1. [Google Cloud コンソール](https://console.cloud.google.com/) で**この道具専用の新しいプロジェクト**を作る（YouTube API の規約で、1つのプロジェクトを複数のアプリで使い回せないため）
2. 「API とサービス」→「ライブラリ」で **YouTube Data API v3** を有効にする
3. 「認証情報」→「認証情報を作成」→「API キー」
4. 作ったキーの「API の制限」で **YouTube Data API v3 だけ**を選んで保存する
5. キーを Cloudflare に入れる（画面に貼り付けを求められます。キーはファイルにもチャットにも書かないでください）

```bash
npx wrangler secret put YOUTUBE_API_KEY
```

APIキーの考え方はノウハウ図書館の「APIキーの正体とGoogle APIキー・OAuth IDの設定方法」も参考になります。分からないところは Claude Code に「YouTube Data API v3 のキーを発行したい」と聞けば進みます。

### 4. 公開する

```bash
npx wrangler deploy
```

最後に `https://shitami.<あなたのサブドメイン>.workers.dev` のような URL が出ます。

### 5. 鍵をかける（Cloudflare Access）

この時点では、URL を知っている人なら誰でも使えます。他人にあなたの1日1回を使われないよう、自分だけが開けるようにします。

1. Cloudflare のダッシュボード →「Workers & Pages」→ `shitami` を開く
2. 「Access」タブ →「Protect this Worker behind Access」
3. 「すべてのトラフィック」を保護する設定にし、ポリシーで自分のメールアドレスだけを許可する
4. 「Apply Access」

初めて Access（Zero Trust）を使うときは、無料プランの登録でクレジットカードの入力を求められます（無料プランでは課金されません）。
設定できると、画面上部の「鍵がかかっていません」の表示が消えます。

### 6.（任意）お金の根拠を Web で調べる

OpenAI の APIキーを入れると、「お金が動いている根拠」と「成り立たない根拠（反証）」を Web 検索で調べる欄が埋まります。入れなければ、その欄が空になるだけです。

```bash
npx wrangler secret put OPENAI_API_KEY
```

OpenAI 側で月の利用上限を必ず設定してください。この道具からの呼び出しは1日2回までに制限しています。

## 使い方

1. 公開した URL を開き、テーマ（例：「作業用BGM」「lofi」）と地域を選んで「調べ切る」を押す
2. 5〜10分ほど待つ。調べている間はページを開いたままにする（閉じても段ごとに保存しているので「続きから調べる」で再開できます）
3. 「結果を開く」で1枚のページが出る。結果は30日で自動的に消えます（YouTube API の規約に合わせています）

### 結果の見方

- **サムネ**は並べて眺める材料です。伸びた理由をサムネだけのせいにしないでください
- **真似**は題名の型までにして、中身で1つ足すものを決めてください。テンプレートどおりの量産は、YouTube の収益化の対象外になることがあります
- **撤退条件**に当たったら、同じ束の隣のテーマを見てみてください
- **自分で確かめること**のリストに、所要時間の目安が付いています。上から順に

## 費用

| 項目 | 無料枠 | 月額 |
|---|---|---|
| Cloudflare Workers | 1日10万リクエスト（調べ切り1回で数千回） | 0円 |
| Cloudflare KV（台帳と結果） | 1日1,000回の書き込み、1GBまで | 0円 |
| Cloudflare Access | 50人まで | 0円 |
| YouTube Data API | 1日10,000 units（検索は100回）。超えると止まるだけで課金はない | 0円 |
| OpenAI（任意） | — | 1回 約7円 |

## 止め方・消し方

- 使うのをやめる：`npx wrangler delete`（Worker を消す）
- キーを無効にする：Google Cloud コンソールの「認証情報」でキーを削除する
- 保存した結果を消す：Cloudflare のダッシュボード →「Storage & Databases」→「KV」で `shitami` の名前空間を削除する

## 仕組み

```
あなたのブラウザ（計算する）
   │  /api/*
   ▼
Cloudflare Access（あなただけ通す）
   ▼
Worker（キーを付けて中継するだけ。1日1回の台帳、結果の保存）── KV（30日で消える）
   ├─▶ YouTube Data API
   ├─▶ YouTube の検索候補
   └─▶ OpenAI（任意）
```

- 調べ切りの計算はブラウザの中で回します。Cloudflare の無料プランでは1回の処理に使える時間が短く、数千回の呼び出しを Worker の中で回せないためです
- APIキーは Worker の中にだけあり、ブラウザには出ません
- 検索の回数は Worker が数えていて、1日の上限（`wrangler.jsonc` の `SEARCH_DAILY_CAP`、既定95回）を超える呼び出しを断ります
- 始める前に1 unit だけ使ってキーを確かめます。キーが間違ったまま1日分を使い切ることはありません

## 分かっている制約

- YouTube の検索候補は公式に公開されていない仕組みを使っています。使えなくなったら、テーマの語だけで探します
- サムネのクリック率は、チャンネルの持ち主しか見られません
- ライブ配信は再生時間が0秒で返るので、形式は「不明」として分けています

## もう一段かたくする（任意）

Access の後ろにあることを Worker 側でも確かめたい場合は、`wrangler.jsonc` の `ACCESS_TEAM`（Zero Trust のチーム名）と `ACCESS_AUD`（Access アプリケーションの AUD タグ）を入れて、もう一度 `npx wrangler deploy` してください。トークンの署名・宛先・期限が合わない呼び出しを断ります。

## 開発

```bash
npm test          # テスト
npm run dev       # 手元で動かす（.dev.vars に YOUTUBE_API_KEY=... を書く。git には入りません）
```

計算の中身は `src/deep/`（段の配分は `src/deep/plan.js`）、中継は `worker/index.js`、画面は `public/index.html` と `web/app.js` です。
